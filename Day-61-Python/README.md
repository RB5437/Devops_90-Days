# Day 61: Python for DevOps - Getting Started

## Concepts Covered:
- Why Python is essential for DevOps Engineers
- What, Why, and How of "Python for DevOps"
- Setting up Python development environment in VS Code
- Writing and running the first Python script
- Understanding Python script execution from terminal

## Key Learning:
- Python helps DevOps engineers automate repetitive tasks like server health checks, log analysis, cloud resource management (AWS Boto3), and CI/CD scripting.
- Learned how to set up a project folder structure (Day-01 inside Python_For_DevOps).
- Created and executed the first Python script (`my-first-file.py`) using `print("Hello, World!")`.
- Learned to run Python scripts via terminal using `python ./my-first-file.py`.
- Understood basic terminal navigation commands (`ls`, `cd`) while working with Python projects.

## Practical / Hands-on:
1. Created project folder: `Python_For_DevOps`
2. Inside it, created `Day-01` folder
3. Created file `my-first-file.py`
4. Wrote code:
   ```python
   print("Hello, World!")
   ```
5. Ran the file from terminal:
   ```bash
   cd Day-01
   python ./my-first-file.py
   ```
6. Output:
   ```
   Hello, World!
   ```

## Why This Matters for DevOps:
Python is the glue language for DevOps - used for writing automation scripts, interacting with AWS APIs (Boto3), parsing logs, monitoring systems, building AI agents, and creating custom CLI tools for CI/CD pipelines.
