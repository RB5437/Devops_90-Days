# Auto Scaling

Auto Scaling automatically adjusts the number of EC2 instances based on demand.

---

## Purpose

- Maintain performance
- Ensure high availability
- Optimize cost

---

## Key Features

- Scale Out → Add instances
- Scale In → Remove instances
- Replace unhealthy instances

---

## Types of Scaling

- Dynamic Scaling → Based on metrics (CPU usage)
- Manual Scaling → Fixed number
- Scheduled Scaling → Based on time

---

## Example

- CPU > 70% → Add instance
- CPU < 30% → Remove instance

---

## Real-World Use

Handles traffic spikes automatically without manual intervention.

---

## Interview Tips

- Auto Scaling = High availability + cost optimization
- Works with Load Balancer
- Uses Launch Template

---

## Summary

Auto Scaling ensures applications remain responsive and cost-efficient by adjusting capacity automatically.
