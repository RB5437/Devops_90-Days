# Launch Template

A Launch Template is a configuration blueprint used to create EC2 instances with predefined settings.

---

## Includes

- AMI ID
- Instance type
- Key pair
- Security groups
- User Data script

---

## Key Benefits

- Reusable configuration
- Version control support
- Required for Auto Scaling

---

## Real-World Use

Used by Auto Scaling Groups to launch identical EC2 instances automatically.

---

## Interview Tips

- Launch Template = EC2 configuration blueprint
- Replaces Launch Configuration (older method)
- Supports versioning

---

## Summary

Launch Templates ensure consistency and automation when launching EC2 instances.
